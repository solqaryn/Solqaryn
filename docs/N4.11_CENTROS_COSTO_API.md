# N4.11 — Centros de costo: contrato API verificado

Estado: evidencia técnica factual para `N4.11.H.2.API_DOCUMENTATION`.

## Alcance

Este documento describe únicamente el contrato observable en `Desarrollo`. No declara `LISTO_REAL`, no autoriza merge/deploy y no sustituye los tests ni los gates causales.

## Base y seguridad

El controlador es `CentrosCostoController`, expuesto bajo la ruta base `centros-costo`. Está protegido con `[Authorize]` y cada operación exige un permiso explícito del módulo `Finanzas` mediante `RequierePermiso`.

## Endpoints

| Método | Ruta | Permiso | Comportamiento observable |
| --- | --- | --- | --- |
| GET | `/centros-costo` | `Ver` | Busca con filtros `termino`, `tipo`, `sucursalId`, `activo`; pagina con `pagina` y `tamanoPagina`. La respuesta incluye `items`, `total`, `pagina` normalizada a mínimo 1 y `tamanoPagina` limitado a 1..100. |
| GET | `/centros-costo/activos` | `Ver` | Devuelve centros activos, opcionalmente filtrados por `tipo` y `sucursalId`. |
| GET | `/centros-costo/{id}` | `Ver` | Devuelve el centro por id; responde 404 con `Centro de costo no encontrado.` cuando no existe. |
| POST | `/centros-costo` | `Crear` | Crea desde `CreateCentroCostoDto`; responde `201 Created` mediante `CreatedAtAction(GetById)` y mensaje `Centro de costo creado correctamente.` |
| PUT | `/centros-costo/{id}` | `Editar` | Actualiza desde `UpdateCentroCostoDto`; responde 404 si el id no existe. |
| PATCH | `/centros-costo/{id}/activar` | `Activar` | Cambia el estado a activo; responde 404 si el id no existe. |
| PATCH | `/centros-costo/{id}/desactivar` | `Desactivar` | Cambia el estado a inactivo; responde 404 si el id no existe. |
| DELETE | `/centros-costo/{id}` | `EliminarLogico` | Ejecuta borrado lógico a través del servicio; responde 404 si el id no existe. |

## DTOs públicos observables

### `CreateCentroCostoDto`

- `codigo: string`
- `nombre: string`
- `descripcion: string?`
- `tipo: TipoCentroCosto`, con valor por defecto `Sucursal`
- `sucursalId: int?`

### `UpdateCentroCostoDto`

- `codigo: string`
- `nombre: string`
- `descripcion: string?`
- `tipo: TipoCentroCosto`
- `sucursalId: int?`
- `activo: bool`

### `CentroCostoDto`

Incluye `id`, `codigo`, `nombre`, `descripcion`, `tipo`, referencia opcional a sucursal (`sucursalId`, `sucursalCodigo`, `sucursalNombre`), estado (`activo`, `eliminado`), metadatos de eliminación, usuarios de creación/actualización y timestamps de creación/actualización.

## Envelope y errores

El controlador usa `ApiResponse<T>` para respuestas exitosas y de error. Los `404` de lectura, actualización y cambio de estado usan el mensaje `Centro de costo no encontrado.`. El borrado lógico exitoso usa `Centro de costo eliminado correctamente.`.

## Límites de esta evidencia

Este documento no afirma aislamiento multi-tenant por `EmpresaId`, comportamiento de Producción ni garantías no visibles en el código actual. Las reglas de validación de payload se verifican en los validators y tests correspondientes; no se inventan aquí requisitos adicionales.
