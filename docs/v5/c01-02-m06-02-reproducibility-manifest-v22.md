## A1 — Procedimiento de reproducción, errores y controles negativos

La reproducción requiere permisos de **solo lectura** a GitHub, no acceso a datos reales. Tomar el SHA de la tabla y verificar el diff contra su padre: `git show --stat <SHA>`, `git diff <PADRE> <SHA> -- <ruta>`, `git rev-parse <SHA>:<ruta>`; comparar los blobs y la configuración de workflow, no solo el nombre del test. Consultar `GET /repos/solqaryn/Solqaryn/commits/<SHA>/check-runs?per_page=100`, exigir `head_sha` igual, `status=completed` y `conclusion=success` en **cada check pertinente**. Para la regresión física de M05.06, examinar el job `136732965290`: ejecuta explícitamente en GitHub-hosted `npx playwright test e2e/c01-02-m05-06-regression-a11y.spec.ts --config=playwright.c15-04-m05-04-real.config.ts --workers=1 --retries=0`; logs `Running 5 tests` y `5 passed (11.6s)` con contenedor MySQL 8.4.13. Este comando depende de servicios y credenciales **efímeras de CI**, nunca se presenta como prueba realizada en máquina local.

**Negativo:** `SKIPPED/CANCELLED/FAILED/QUEUED/IN_PROGRESS` de un check **requerido** NO equivale a PASS. **Frontera:** xUnit con mocks, EF InMemory o SQL fixture prueban ese contrato, no producción o todos los recursos. **Error:** comparar solo el commit original con un descendiente que alteró el test, proveedor o workflow sin cotejar blobs invalida la equivalencia. Procedencia pública: https://github.com/solqaryn/Solqaryn/actions/runs/44867057337/job/136732965290 y https://github.com/solqaryn/Solqaryn/commit/844d7fead192cf0f661ac8ae6f1b934860eca6ab.
