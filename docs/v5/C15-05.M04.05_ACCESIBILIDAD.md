# C15-05.M04.05 — Responsive, teclado, foco, etiquetas y contraste

## Riesgo y alcance (V15 R1)
Verificación ejecutable y aislada de la superficie Angular privada \`/plataforma/auditoria-operativa-v5\`. No añade endpoints, acceso a Google Sheets, CLAIM, cambios de RBAC backend, integraciones ni escrituras institucionales. El guard \`plataformaGuard\` sigue siendo obligatorio; las pruebas sintéticas NO certifican JWT real, autorización de API o datos de otro tenant.

## A0 — Requisitos y aceptación
- Chromium/Playwright con viewports 320, 390, 768 y 1280 px, cuatro tarjetas y ausencia de overflow horizontal mayor de dos píxeles.
- Navegación mediante teclado, foco visible del enlace de retorno y activación con Enter; modo reduce-motion.
- Landmarks \`main\` y sección nombrada, jerarquía h1/h3, enlace con nombre accesible, ausencia de formularios o botones de aprobación.
- Contraste de texto calculado desde estilos reales del navegador y exigencia WCAG AA >= 4.5:1 para título, indicador y enlace.
- Caso negativo: backend sintético devuelve sesión de plataforma sin admin; la vista no debe mostrar controles internos.

## A1–A3 — Pruebas y límites
Los cuatro tests son afirmaciones positivas, negativas y de frontera que pueden fallar ante defectos reales de UI. Se ejecutan en el workflow \`v5-plataforma-browser-guards.yml\`, con Angular local y Chromium instalado en GitHub-hosted. Las sesiones usan mocks y token ficticio. A2: el caso no-admin verifica fail-closed local; JWT/RBAC backend real corresponde a otros scopes y no se declara PASS aquí. A3: Playwright real de frontend; MySQL, EF, HTTP autenticado de proveedor externo, datos reales y producción NO_APLICA porque no se modifican.

## A4 y A5
A4 solo puede declararse después de verificar el SHA exacto con Scope Lock, procedencia V5, lint/build Angular y resultado real completado con éxito del job browser que incluya esta suite. Un check QUEUED, IN_PROGRESS, CANCELLED, SKIPPED o FAILED no vale PASS. A5 requiere una Task Javier distinta, revisión de los asserts y de los resultados. No autoriza QA/main/PROD.
