# C15-05.M04.04 — Navegación, mensajes y prevención de doble acción

## Alcance (R1)
Verificación ejecutable por Angular/Vitest de la superficie de auditoría operativa V5, que es explícitamente **solo lectura**. No se crea formulario, botón de CLAIM/A5, envío de datos, API, reintento o estado institucional vivo. Si el producto futuro introduce formularios o doble envío, exige otro scope con pruebas y backend idempotente; aquí la prevención es **ausencia verificable de cualquier control de mutación**.

## A0 — Criterios
- Ruta exacta privada bajo guard; no se añade permiso ni un segundo acceso público.
- Para una sesión de plataforma simulada de administrador, mensaje «Guía estática» y ausencia de datos vivos; cuatro controles de orientación.
- Un único enlace accesible de retorno a `/plataforma`; sin formularios, botones, campos, roles button ni doble-submit posible.
- Para sesión sin administrador, contenido privado oculto y alerta explícita; no se brinda posibilidad de aprobar o reintentar acciones operativas.

## A1–A3 — Evidencia y límites
Cuatro pruebas Vitest que usan TestBed, componente real, ruta real y `PlataformaSesionService` simulado. Incluyen positivas, negativa de autorización y ausencia de controles de doble acción. No son autenticación JWT real ni prueba de backend; A2 valida únicamente protección visible. A3 MySQL/HTTP/proveedor no aplica; esta microtarea no toca persistencia, servicio o conexión externa. La navegación/foco/responsive en Chromium se prueba separadamente por `C15-05.M04.01` y `C15-05.M04.05`; no se atribuyen tests ajenos como propios.
