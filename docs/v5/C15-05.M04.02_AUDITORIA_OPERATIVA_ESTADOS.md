## A0 y riesgo
M04.01 entregó una guía estática y ruta protegida. M04.02 añade estados de carga, vacío, error, éxito y permisos asociados a una revalidación real de la sesión de plataforma con el backend existente. El estado inicial autorizado es vacío (cero datos operativos conectados); sin sesión es sin_permiso. Al pulsar, el servicio invalida la sesión cacheada y se oculta el contenido hasta recibir confirmación. HTTP 401/403 deniega; HTTP 500/error de red permanece restringido; carga impide petición duplicada. JWT local, EmpresaId y el navegador nunca conceden autorización.
