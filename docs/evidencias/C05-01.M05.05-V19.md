# C05-01.M05.05 — Seguridad negativa de superficie de catálogo

Task autora DEV05, 2026-11-16. Riesgo R2 por casos adversariales de permisos; sólo se añaden tests de navegador y workflow para un componente Angular existente, sin modificar lógica del frontend, backend o permisos. No se permiten claims JWT o tenant runtime sobre fixtures simulados.

## A0
Tres rechazos causales de navegación privada /plataforma: (1) 200 aparentemente satisfactorio pero sesión de Empresa no es autoridad de Plataforma; (2) 200 con ámbito Plataforma pero isAdministrador=false tampoco concede acceso; (3) 403 con mensaje de diagnóstico sintético oculto, sin escrituras HTTP al ser denegado. Se exige redirección real del browser a login, ausencia de biblioteca y tokens privados y ningún mensaje sensible visible. El contrato fail-closed ya existe; se prueba contra él.

## A1–A3
Las tres pruebas se ejecutan realmente en Chromium vía GitHub-hosted con una ruta HTTP interceptada deliberadamente. Cada aserción puede fallar ante una regresión de guard, fuga de contenido o mutación de red. A2 limitada a interfaz/fixtures sintéticos; NO prueba autorización real, JWT, revocación del servidor, aislamiento empresa A/B ni abuso de datos. A3 exige npm ci, tipado/lint, build Angular y Chromium. MySQL/EF NO_APLICA porque el código de aplicación no cambia.
