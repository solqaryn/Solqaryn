## Recovery exact-head del harness E2E

La primera certificación exact-head sobre Angular 22 detectó un fallo real del harness antes de Playwright: el job heredaba `PORT=5005` para la API y Angular CLI 22 respetó esa variable al ejecutar `ng serve`, por lo que intentó ocupar el puerto 5005 pese al argumento `--port 4200`. El log causal reportó `Environment variable "PORT" detected. Using port 5005` y `Port 5005 is already in use`.

La corrección es exclusiva del harness DEV: el paso `Iniciar Angular` elimina `PORT` del entorno del proceso frontend antes de ejecutar `npm start -- --host 127.0.0.1 --port 4200`. La API conserva 5005; el frontend conserva 4200. No cambia código de negocio ni configuración de QA/PROD. El cierre sólo es válido cuando aceptación integral, E2E de Fase 4 y dictamen final pasen sobre el mismo HEAD posterior a esta corrección.
